## 🛒 Major Project: ShopSphere

**ShopSphere** is a Java-based e-commerce application built to demonstrate web development, database connectivity, and application design using Java technologies.

### Key Features

**Customer module**
- User registration and login
- Product browsing and product details
- Shopping cart and wishlist
- Checkout and payment workflow
- Order history and profile management

**Admin module**
- Admin login and dashboard
- Product and category management
- Order and user management
- Coupon management
- Reports and dashboard information

### Technologies Used

- Java
- JSP and Servlets
- JDBC
- MySQL
- Apache Tomcat
- Apache Maven
- HTML, CSS and Bootstrap
- Java Swing for the desktop administration module

**Project folder:** `ShopSphere`

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the folder of the experiment you want to explore.
3. Read the experiment's README file, if available.
4. Install the required JDK and dependencies.
5. For database-based experiments, configure the MySQL database and connection settings.
6. Follow the relevant project's build and execution instructions.

For ShopSphere, configure the database and Maven environment, build the project, and deploy it to Apache Tomcat according to its project configuration.
