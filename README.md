# ShopSphere – Java E-Commerce Project

## Project Overview
ShopSphere is a Java-based e-commerce application developed as an academic project. It includes a web application, an administration module, and database-related files.

## Project Structure
- `database/` – Database-related files.
- `swing-admin/` – Java Swing administration module.
- `web/` – Web application files.
- `pom.xml` – Maven project configuration.
- `Dockerfile` – Docker configuration.
- `.gitignore` – Files excluded from version control.

## Technologies
- Java
- Maven
- Java Swing
- Web technologies
- Database integration

## How to Run
1. Clone or download this repository.
2. Open the project in a Java IDE such as Eclipse or IntelliJ IDEA.
3. Ensure Java and Maven are installed.
4. Configure the database according to the project configuration.
5. Build the project using Maven and follow the setup instructions for the relevant module.

## Purpose
This project is developed for academic learning and demonstrates Java application development, web technologies, and database integration.
