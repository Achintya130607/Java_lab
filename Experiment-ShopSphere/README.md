# ShopSphere

## Project Description
ShopSphere is a Java-based e-commerce web application developed using JSP, Servlets, JDBC, Maven, and MySQL.

## Features
- User Registration and Login
- Product Listing
- Shopping Cart
- Wishlist
- Order Management
- Admin Panel

## Technologies Used
- Java
- JSP and Servlets
- HTML, CSS, Bootstrap
- JDBC
- MySQL
- Apache Tomcat
- Maven

## Project Structure
The `ShopSphere` folder contains the project documentation and source code.

## How to Run
1. Install JDK, Maven, Apache Tomcat, and MySQL.
2. Configure the database connection.
3. Build the project using Maven.
4. Deploy the generated WAR file to Tomcat.
5. Start Tomcat and open the application in your browser.
