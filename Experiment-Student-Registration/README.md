# Experiment - Student Registration System

## Objective
To develop a GUI-based Student Registration System using Java Swing.

## Project Description
This project allows users to enter student details through an interactive registration form. It validates the entered information and displays the registration details after successful submission.

## Technologies
- Java
- Java Swing
- AWT
- Event Handling

## Files
- `StudentRegistration.java` - Main Java source code.
- `StudentRegistration.png` - Screenshot of the application.
- `README.md` - Project documentation.

## How to Run
1. Install the Java Development Kit (JDK).
2. Compile the Java source file:
   `javac StudentRegistration.java`
3. Run the application:
   `java StudentRegistration`

## Output
The application displays a student registration form and shows the submitted student details after successful registration.
